## 删 / 改一条数据

新增一条记录（"添加""记一笔""加一条"）：
`append #todos item={text: #new.value}`，随后清空输入：
`append #todos item={text: #new.value} ; set #new value=""`。

**删除一条数据**用 `remove_where`，配行内事件的行上下文：

```puppet
on #del click as t: remove_where #todos as r where r.text == t.text
```

- `del` 只删**节点**（界面元素），删不了数据源里的项——`del #todos[0]` 是语法错误。
- 处理器不写 `as t` 就没有"用户点中的是哪一行"，带绑定名的动作会报 `ROW_CONTEXT` 错误。

**修改一条数据**（"编辑""更新""勾选完成""标记"）用 `update_where`：

```puppet
on #done change as t: update_where #todos as r set done=#done.value where r.text == t.text
```

匹配键要能唯一对上行（`r.text == t.text`）；数据项没有 id，靠**字段相等**定位。
