## 布局节奏（骨架纪律）

值选对了但**骨架乱**，照样难看。这份管的是"东西怎么摆"。

### 一条主列 + 分组，不要到处嵌套

**最稳的骨架：一个 `col` 主列，里面按功能区切成若干分组**。默认不要超过三层：

```puppet
add #root window #win title="记账" w=720 h=560 bgcolor=#f8fafc primary=#2563eb
add #win col #main pad=16 gap=16

add #main navbar #bar title="记账"

add #main col #summary gap=8          // ① 概览区
add #main col #list_area gap=8 flex=1 // ② 列表区（吃掉剩余高度）
add #main row #actions gap=8          // ③ 操作区
```

- **顺序即信息架构**：概览 → 主体 → 操作，人从上往下读。
- 需要"并排"时才用 `row`；**不要为对齐而嵌套空 `col`**——那是 `gap` 的活。
- 嵌套超过三层时问自己：这一层能靠 `gap` 或 `pad` 省掉吗？

### 对齐靠 flex / gap / justify，不靠手填 pad

**这是最常见的难看来源**：左右两栏用不同 `pad` 硬凑对齐。

```puppet
// ✗ 差：靠 pad 凑对齐，改一处就全乱
add #row1 row gap=0
add #row1 text #a text="名称" w=120 pad=4
add #row1 text #b text="金额" w=100 pad=6

// ✓ 好：靠 flex 分配剩余空间，天然对齐
add #rows col #list gap=0 flex=1
add #list row #line gap=8 pad=8
add #list text #a text=m.name flex=1        // 吃掉剩余
add #list text #b text=str(m.amount) w=80   // 固定宽，右栏就齐了
```

- 两端对齐：`justify="space-between"`；均分：给每个子项 `flex=1`。
- **不要用空格或空 `text` 当占位符**——`flex` 就是干这个的。

### 主次要拉开，别所有区块一样重

平铺 = 没有重点。**用分区 + 尺寸差**建立主次：

| 区块 | 做法 |
|---|---|
| 主区（用户常看的） | `flex=1` 占最大，给卡片面（`bgcolor` + `radius`） |
| 次区（辅助信息） | 不占高度，弱文字色，**不加卡片底** |
| 操作区 | 贴近底部，`gap=8`，主按钮在前 |

### 溢出必须先想好（否则一定出事）

列表/长文本一定会撑破容器。**三种处置，选一个写进去**：

```puppet
add #main list #rows flex=1                 // ① 列表：flex=1 + 容器可滚动
add #main text #note text="..." wrap=true   // ② 长文本：wrap=true 换行
add #main col #scroll flex=1 scroll=true    // ③ 整体滚动容器
```

- **列表几乎总是 `flex=1`**——不给它 `flex` 它要么塌成 0 高，要么把窗口撑长。
- 定宽容器里的长文本必须 `wrap=true`，否则横向溢出。
- **窗口尺寸是变量**：别写死像素位置（`x=` / `y=`），让 `flex` + `pad` 自适应。

### 空态与加载态：不留白板

数据没到时界面是空的——**空着就是"坏了"的观感**：

```puppet
add #main text #empty text="还没有记录，点「新建」开始" fg=#94a3b8 visible=false
on #items change:
    set #empty visible=count(#items) == 0
```

### 自查清单（改完扫一眼）

1. 主列之外，有没有超过三层的嵌套？→ 试着用 `gap` 压平。
2. 有靠 `pad` 手凑对齐的地方吗？→ 改 `flex` / `justify`。
3. 列表给了 `flex=1` 吗？长文本给了 `wrap=true` 吗？
4. 所有区块是不是一样重？→ 挑一个当主区，其余变弱。
5. 数据为空时，界面是白板吗？→ 补空态提示。
6. 有写死 `x=` / `y=` 的地方吗？→ 换 `flex`。
