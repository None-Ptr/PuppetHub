## 列表与模板

清单 / 表格 = 数据源 + 模板（语言没有循环——重复的结构由模板行承担）：

```puppet
add #root template #tpl as t
add #tpl row #r
add #r text #t1 text=t.text
add #tpl button #del text="删"
data #todos = [] of {text: str = ""}
add #main list #items source=#todos template=#tpl
```

- 行数随 `append` 自动增长；模板内用**绑定名**（`t.字段`）读当前行的数据。
- 行内按钮要"知道点的是哪一行"，处理器必须 `as t`（见"删改数据"技能）。
- **行内输入框的正解**：值绑数据源字段 + `change` 回写——
  `add #tpl input #ed value=t.text` + `on #ed change as e: update_where #todos as r
  set text=e.value where r.text == t.text`。行内控件的**控件状态不按行隔离**
  （`ROW_INPUT_SHARED` 警告）——不要指望 `#ed.value` 在行内记住各自的输入。
- 条目计数：`text="共 " + str(count(#todos)) + " 条"`——`count` 是**活绑定**，
  数据变化自动重算，不需要手写刷新。
- 数据项没有 id；定位某一行靠字段相等（`where r.text == t.text`）。
