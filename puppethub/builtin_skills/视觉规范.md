## 视觉规范（选值纪律）

词汇表给了能力，这份给**具体往哪填**。风格段（`plain` / `phosphor`）定的是"走什么路子"，
这里定的是"路子定了之后，值怎么挑"。

### 颜色：三档就够

| 档位 | 用途 | 值 |
|---|---|---|
| **主色** | 主行动、聚焦环、进度条 | 一处定色：`add #root window #win primary=#2563eb` |
| **中性阶** | 底 / 面 / 线 / 主文 / 次文 | `#f8fafc` 页底 · `#ffffff` 卡片面 · `#e5e7eb` 分隔线 · `#0f172a` 主文 · `#64748b` 次文 · `#94a3b8` 弱文 |
| **语义色** | **只**给成功/警告/错误 | `#16a34a` 成功 · `#dc2626` 错误 |

- **深底必须配浅字，浅底必须配深字**。对比度不够不是"高级灰"，是看不清。
- 全篇颜色总数**控制在 5–6 个以内**。层级靠字号字重表达，不靠加颜色。
- 绿/红**不当装饰**——它们一旦被用来"点缀"，错误提示就失去了警示力。

### 间距：四档挑两档

`pad` / `gap` **从 4 / 8 / 12 / 16 / 24 里挑**，一个界面用两三档就够：

| 值 | 场合 |
|---|---|
| `4` | 紧邻元素（图标与文字、标签与值） |
| `8` | 同组元素之间（列表行内、按钮组） |
| `12` | 卡片内边距、区块内间距 |
| `16` | 主容器内边距（`pad=16` 是最常用的安全值） |
| `24` | 大区块之间、页面级留白 |

间距**忽大忽小比没有间距更乱**。写 13 不会有任何报错——但一套有韵律的值是好看的**充分条件**。

### 字号层级：三件套

**层级 = 大 `size` + 粗 `weight` + 深 `fg`**，三者一起用才有层级感：

```puppet
add #card col #c1 flex=1 pad=16 gap=6 radius=12 bgcolor="#ffffff" border="1 #e5e7eb"
add #c1 text #title text="总支出" size=13 weight="bold" fg="#0f172a"
add #c1 text #value text=str(sum(#records, "expense")) size=24 weight="bold" fg="#0f172a"
add #c1 text #hint  text="本月累计" size=11 fg="#94a3b8"
```

- 标题：`size` 大 1–2 档 + `weight="bold"` + `fg` 用主文色
- 数值/重点：`size` 最大 + `weight="bold"`
- 辅助说明：`size` 小 + `fg` 用弱文色（**不要**把说明文字设成和正文一样深）

### 容器：卡片配方

"白色面 + 淡边框 + 圆角 + 内距"是最稳的卡片做法：

```puppet
radius=12 bgcolor="#ffffff" border="1 #e5e7eb" pad=16
```

- `radius`：**8 / 12 / 16** 三档。小控件 8，卡片 12，大面板 16。
- `border` 格式是 `"宽度 颜色"`——`"1 #e5e7eb"`（淡分隔线）。**别用纯黑 `#000000` 描边**。
- `shadow`：**轻用**。它是强度数字（`shadow=2` 上下），大模糊低透明度才不脏。
- `gradient`：只给头图 / 英雄区**一处**，两色且相近。"一次只炫一处"。

### 反馈：让界面"活"

主按钮给 `states`，hover 有反应：

```puppet
add #entry button #save text="保存" icon="save" states={hover: {bgcolor: "#1d4ed8", fg: "#ffffff"}}
```

按钮配 `icon=`（图标清单见词汇边界）。空状态用 `visible` 切换的提示文字，别留一片空白：

```puppet
add #main text #empty text="还没有记录" fg="#94a3b8" visible=false
```

### 自查清单（改完扫一眼）

1. 颜色超 6 个了吗？→ 合并到主色 + 中性阶。
2. 间距值有两个以上"怪数"（如 10 / 13 / 15）吗？→ 归到 4/8/12/16/24。
3. 页面有层级吗？标题、正文、说明**看得出三级**吗？
4. 深底配浅字了吗？（特别是深色卡片上的文字）
5. `#000000` 或 `#ffffff` 当描边色了吗？→ 改用 `#e5e7eb` 这类淡灰。
6. 主按钮 hover 有反馈吗？
