## 语言速查（写任何东西之前先看这份）

语言故意做小：**无循环、无自定义函数、无条件表达式**。复杂逻辑落进 `capabilities.py`。
一行一条语句；唯一例外是行为头 `on … :` 后面可跟缩进的动作体（多行 ≡ 单行 `;` 连接）。

### 动词（全部就这些）

| 动词 | 干什么 |
|---|---|
| `add` | 增节点（`add #父 类型 #id 属性…`） |
| `set` | 改属性，或改状态标志（`visible` / `disabled`） |
| `del` | **删节点**（不是删数据！） |
| `move` | 移动节点到新父 |
| `upsert` | 有则改、无则增 |
| `data` | 声明数据源 |
| `on <目标> <事件>:` | 处理器（动作体可缩进多行） |
| `listen` | 订阅数据源 |
| `call` | 调能力 → 落进槽 |
| 探针 | `tree` / `get` / `where` |

### 集合原语（改数据源内容）

`append` · `remove` · `remove_where … as r where …` · `update_where … as r set …` · `clear` · `sort`

### 属性组

- **盒模型**：`pad` `margin` `bgcolor` `gradient` `radius` `border` `shadow` `opacity`
- **布局**：`gap` `justify` `align` `wrap` `flex` `scroll` `w` `h` `x` `y` `offset` `scale` `rotate`
- **排版**：`fg` `size` `weight` `italic` `font` `tooltip`
- **内容**：`text` `icon` `src` `fit` `initials` `value` `selected` `min` `max` `step` `placeholder` `title` `primary`
- **引用**：`source` `template` `options`
- **元**：`states` `animate` `duration` `curve`

**状态标志**（可读可写）：`hover` `focus` `pressed` `error` `visible` `disabled`

### 表达式与引用

表达式**只出现在**：属性值 / `when` / 动作参数 / `data` 初值里。

- 引用节点属性：`#id.attr`
- 模板行内用**绑定名**：`t.text`（不是 `#t.text`）

### 模板（列表行的唯一做法）

```puppet
add #root template #tpl as t        // 声明模板
add #tpl row #line gap=8            // 模板内的行内容
add #main list #L source=#items template=#tpl
```

### 消息与槽（用户操作给的值、能力的值）

- `#id.value`——输入 / 选择 / 进度的值。**用户操作给出的值先进状态**：
  在 `change` / `submit` 处理器里直接读它。
- `#id.selected`——下拉 / 分页的**序号**（从 0 起）。要选中的**文本**读 `value`。
- `#slot.status` / `#slot.value`——能力槽；值类属性可直接绑定它，自动重算。
- `count(#data)`——计数（活绑定）。
- **`sum(#data, "字段")`**——合计（活绑定，数据变了自动重算）。

### 三个高频坑（踩了就返工）

1. **删/改一条数据**用 `remove_where` / `update_where`——`del` 只删**节点**。
2. **求和/比较**先 `num(...)` 转换——`+` 有一侧是字符串就是**拼接**，静默出错。
3. **行内事件**必须 `as t` 拿行上下文——否则读不到这一行的数据。

### 注释与颜色

- 注释用 `//`（写回时会丢，**意图写 `DESIGN.md`**）。
- `#` 后 6/8 位十六进制 = 颜色（如 `#2563eb`）；其他 = 地址。**不用 3 位简写**。
