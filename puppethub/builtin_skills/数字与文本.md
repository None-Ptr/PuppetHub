## 数字与文本

输入框的值**永远是字符串**。`+` 只要有一侧是字符串就是拼接：`"1" + "2"` 得 `"12"`，
**不报错**——求和、合计、金额、数量、单价必须先 `num(...)` 转换：

```puppet
set #total text=str(num(#a.value) + num(#b.value))
```

- `num` 转不动非数字文本会报 `EXPR_TYPE`（不会悄悄给 0）。
- 显示时用 `str(...)` 拼回文本。
- 比较大小（"大于""超过""满 100"）同样先转换：`when num(#price.value) >= 100`。
- 想判断"输入是不是数字"再运算：`num` 报错即是答案——把运算放进
  `when #amount.value != ""` 的分支里，空串先被拦住。
- **合计数据源的某字段**：`sum(#items, "amount")`（两参形式，**活绑定**——append 后
  自动重算，界面不用手刷）。缺该字段的行不计；显示：`text="合计 ¥" + str(sum(#items, "amount"))`。
  语言没有循环——逐行累加写不出来，聚合一律用内建（count / sum）。
