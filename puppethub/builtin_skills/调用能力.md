## 调用能力（call → 槽）

能力 = app 给你的工具（`capabilities.py` 里的函数）。**先看【本 app 的能力】清单**——
签名与说明就在每轮上下文里；没有需要的能力再用 `write` 块加一个。
**纯计算不需要能力**：计数 `count(#data)`、**合计 `sum(#data, "字段")`**（活绑定，
数据变了自动重算）、过滤/取项 `at / first / last / slice / contains` 都是内建。

### 调用语法

```puppet
call send_mail with {to: #user.value, subject: "账单"} into #mail
```

- `into #槽`：结果落在槽上——`#mail.value` 是返回值、`#mail.status` 是五态
  （进行中 / 成功 / 失败 / 超时 / 取消）。
- **槽是可读状态，值类属性直接绑定它**——不要手写"收到结果再 set"：

  ```puppet
  add #content text #reply text="发送结果：" + str(#mail.value)
  ```

  调用完成时绑定自动重算，界面自己更新。
- 调用是**异步**的：`call` 立即返回，能力体在后台跑；同一槽的新调用会取消旧调用（可见）。
- **失败路径必须有人接**：`call` 的 `error` / `timeout` 既没处理器也没订阅 →
  `UNCOVERED_FAILURE` 警告。处理写法：

  ```puppet
  on #mail error: set #reply text="发送失败：" + #mail.status
  ```

### 写一个新能力（`write capabilities.py`）

```python
"""能力说明写在模块 docstring。"""
from puppet import capability

REQUIRES: list[str] = []          # 额外 pip 依赖写这里（语义 = pip 分发名）

@capability(returns="dict")
def send_mail(to: str, subject: str = "") -> dict:
    """发送一封邮件，返回 {id, accepted}。"""
    # 返回值必须可序列化（dict / list / str / 数字 / 布尔）。
    return {"id": "m1", "accepted": True}
```

- **docstring 非空是硬性要求**（它是你发现这个工具的唯一说明书；缺失 = `CAP_NO_DOC`，不注册）。
- 参数类型用注解（str/int/float/bool/list/dict）；缺参数、类型不符 → `CALL_CONTRACT`
  错误，**不会**静默补默认值。
- 调用前先读【本 app 的能力】里的签名——参数名与类型以它为准，不要猜。
