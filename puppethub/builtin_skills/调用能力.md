## 调用能力（call → 槽）

能力 = app 给你的工具（住在 `capabilities.py`）。**先看每轮上下文里的【本 app 的能力】清单**
——签名与说明就在那里；没有你需要的才去写一个（见 `编写能力`）。

### 调用语法

```puppet
call send_mail with {to: #user.value, subject: "账单"} into #mail
```

- `call <能力名> with {参数: 值} into #槽`——结果落在**槽**上。
- **槽是可读状态**：`#槽.status` 取五个值之一 —— `pending`（进行中）· `done`（成功）·
  `error`（失败）· `timeout`（超时）· `cancel`（被取消）；`#槽.value` 是返回值。
  这五个也是**可订阅/可处理的事件名**（`on #槽 done:` 等）。
- **值类属性直接绑定槽**，不要手写"收到结果再 set"：

  ```puppet
  add #content text #reply text="发送结果：" + str(#mail.value)
  ```

  调用完成时绑定**自动重算**，界面自己更新。
- 调用是**异步**的：`call` 立即返回，能力体在后台跑。同一槽的新调用会**取消旧调用**
  （取消是可见的，不是静默丢弃）。

### 纯计算不需要能力

计数 `count(#data)`、**合计 `sum(#data, "字段")`**、过滤取项 `at / first / last / slice / contains`
都是**内建且活绑定**——别为这些写能力。要改数据用 `remove_where` / `update_where`
（详见 `语言速查` 的三个坑）。

### 失败必须先安排

`call` 的 `error` / `timeout` 既没处理器、也没订阅 → **`UNCOVERED_FAILURE` 警告**。

```puppet
on #mail error: set #reply text="发送失败：" + #mail.status
```

**完整失败处理（重试 / 超时 / 降级）见 `能力失败处理`。**
