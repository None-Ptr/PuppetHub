## 读用户输入（交互事件）

**用户操作给出的值先进状态**：`change` / `submit` 触发时，控件值已写进 `#id.value`——
处理器里直接读，不必经由事件载荷：

```puppet
on #add click when #amount.value != "":
    append #records item={amount: #amount.value} ; set #amount value=""
```

- input 打字即 `change`（值持续同步）；回车 / 完成键是 `submit`（载荷带新值）。
- 下拉 `#id.selected` 是**序号**（从 0 起的数字）；要选中的**文本**读 `#id.value`。
- 勾选 / 开关的 `#id.value` 是布尔；滑块 / 进度是数字。
- 程序没写 change 处理器时，input 的 change 仍然只做"值 → 状态"（打字不是动作，
  没有副作用）。
