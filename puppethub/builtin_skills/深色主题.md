## 深色主题（不是浅色反一下）

**白色界面把颜色反过来 ≠ 深色好看**。深色有它自己的一套：**分层靠"亮度接近的几层"，
不是靠阴影**（深底上阴影看不见）。

### 底色要分层：底 < 面 < 悬浮

深色最难的是"卡片浮不起来"。**用三个相接近的深色造层**，不要一个黑到底：

| 层 | 用途 | 值 |
|---|---|---|
| **底** | 窗口背景 | `#0f172a` |
| **面** | 卡片 / 列表行 | `#1e293b` |
| **悬浮** | 弹层 / 高亮行 / 输入框 | `#334155` |

```puppet
add #root window #win title="控制台" w=720 h=560 bgcolor=#0f172a primary=#60a5fa
add #win col #main pad=16 gap=12
add #main col #card bgcolor=#1e293b radius=12 pad=16 gap=8 border="1 #334155"
```

- **深色里"卡片的边"比阴影有用**：`border="1 #334155"` 划出轮廓。
- **绝不用纯黑 `#000000` 当底**——死黑显脏，且层与层之间无空间可降。
- **绝不用纯白 `#ffffff` 当字色**——深底上的纯白刺眼，用 `#f1f5f9` / `#e2e8f0`。

### 文字：三级灰，别只有一档

深底上文字的层级**完全靠灰阶**（因为不能再加颜色了）：

| 层级 | 值 | 用途 |
|---|---|---|
| 主文 | `#f1f5f9` | 标题、正文 |
| 次文 | `#94a3b8` | 说明、标签 |
| 弱文 | `#64748b` | 占位、禁用、时间戳 |

### 主色要提亮，否则"沉"

浅色里的 `#2563eb` 放到深底上会**发暗发脏**。**深色主色统一提亮一档**：

| | 浅色主题 | 深色主题 |
|---|---|---|
| 主色 | `#2563eb` | **`#60a5fa`** |
| 主色悬停 | `#1d4ed8` | **`#93c5fd`** |
| 成功 | `#16a34a` | **`#4ade80`** |
| 错误 | `#dc2626` | **`#f87171`** |

- 深色上的**语义色也要提亮**——暗红在暗底上根本看不出是"红"。
- 强调色**别超过两个**：深色本身已经占了视觉重量，再加彩色就糊。

### 阴影改描边，发光要克制

- `shadow` 在深底上**基本看不见**，别指望它分层 → 用 `border` 代替。
- 想要"科技感发光"：用**一处**主色的 `gradient` 或高饱和 `border`，**不要满屏霓虹**。
- 荧光绿/洋红这类**当强调色最多一处**，多了像玩具。

```puppet
add #main col #hero gradient="135deg #1e293b #334155" radius=16 pad=24
```

### 自查清单（改完扫一眼）

1. 底层是纯黑 `#000000` 吗？→ 改 `#0f172a` 这类带蓝味的深灰。
2. 字色是纯白 `#ffffff` 吗？→ 改 `#f1f5f9`。
3. 卡片能"浮起来"吗（`bgcolor` 比底亮一档 + 有 `border`）？
4. 主色/语义色还是浅色那套吗？→ 提亮一档。
5. 文字只有一档灰吗？→ 分出主/次/弱三级。
6. 霓虹色用了几个？→ 超过一个就减。
7. 还指望 `shadow` 分层吗？→ 换 `border`。
