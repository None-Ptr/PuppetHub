## 诊断速查（收到诊断后先查这里）

引擎把**带行号的诊断**回灌给你。下面的表是「这条码什么意思、怎么修」。
**不要同一个错改两遍**——第二次请换一种写法。

- `SYNTAX`（错误）：该行不符合语法（词法或语法错误），**该行未应用**，不影响本批其余行
- `ID_DUP`（错误）：地址已被占用
- `PARENT_MISSING`（错误）：父地址不存在
- `TARGET_MISSING`（错误）：目标不存在：`set` 的目标 / `move` 的被移节点与新父 / `listen` 的订阅目标 / 探针的目标 / **`fire` 的目标**
- `ANCHOR_MISSING`（错误）：`before` / `after` 锚点不存在
- `MOVE_CYCLE`（错误）：`move` 造成自环或成环
- `DEL_MISSING`（警告）：`del` 目标不存在
- `REF_MISSING`（错误）：引用类属性（`source` / `template` / `options`）指向的目标**不存在**
- `REF_KIND`（错误）：引用类属性指向的目标**存在但类型不对**（如 `template` 指向普通节点）
- `ASSET_REMOTE`（错误）：资源地址是远程地址或绝对路径（`src` 只允许资源目录内的相对路径）
- `ASSET_MISSING`（错误）：资源文件不存在于资源目录（仅在调用方提供了资源根目录时校验）
- `ROW_CONTEXT`（错误）：派发行内事件却无法确定行上下文（不在模板内 / 行序号越界 / 模板未绑定）
- `TEMPLATE_UNUSED`（警告）：模板未被任何列表绑定
- `UNKNOWN_ATTR`（警告）：属性名不在词汇表中（带近似建议）
- `UNKNOWN_TYPE`（警告）：节点类型不在词汇表中
- `UNKNOWN_ICON`（警告）：图标语义名未识别（带近似建议）
- `UNKNOWN_EVENT`（警告）：事件名未识别
- `ATTR_ON_TYPE`（警告）：属性不适用于该节点类型
- `REF_ATTR_EXPR`（错误）：引用类属性写了表达式
- `STATE_LAYOUT_ATTR`（警告）：`states` 中出现布局类属性
- `STATE_UNKNOWN_ATTR`（警告）：`states` 中出现外观白名单之外的属性
- `DISABLED_HANDLER`（警告）：静态 `disabled=true` 的节点却绑定了交互处理器
- `ANIMATE_UNKNOWN`（警告）：`animate` 中出现非语义可动画属性
- `BIND_CYCLE`（错误）：绑定图出现环（编译期）
- `BIND_UNKNOWN_REF`（错误）：绑定的引用目标不存在
- `BIND_EVAL`（错误）：绑定的运行期求值失败（类型不符、除零、未知字段、函数错误）
- `BIND_OVERRIDDEN`（信息）：`set` / `upsert` 覆盖了一个已绑定属性，该绑定被解除
- `UPSERT_KEPT`（警告）：`upsert` 命中**已存在**的地址：只更新**给定属性**，声明里的类型 / 父 / 锚与现状不同而被保留（要改类型用 `del`+`add`，要搬家用 `move`）
- `WHEN_NOT_BOOL`（错误）：`when` 守卫求值结果不是布尔
- `EXPR_TYPE`（错误）：表达式类型不符（不在白名单转换内的混用）
- `EXPR_UNKNOWN_FUNC`（错误）：未知函数
- `EXPR_DIV_ZERO`（错误）：运行期除零
- `CALL_CONTRACT`（错误）：参数缺失 / 多余 / 类型不符
- `CALL_UNKNOWN`（错误）：目标函数不存在
- `CALL_RESULT`（错误）：返回值不可序列化或不符合声明结构
- `CAP_NO_DOC`（错误）：能力的说明文本（docstring）为空——**不予注册**
- `CAP_DEPS_MISMATCH`（警告）：能力模块的依赖声明与实际 import 不一致（不迁移、不缺包）
- `CAP_IMPORT`（错误）：能力模块加载失败（文件缺失或导入抛错）
- `SLOT_TIMEOUT`（错误）：调用超时（观察为超时态）
- `SLOT_STALE_DROPPED`（信息）：旧序号的调用结果到达后被丢弃
- `SLOT_CANCELLED`（信息）：进行中的调用被新调用取消
- `CONVERGENCE_LIMIT`（错误）：处理器级联达到轮次上限（**可见**，带触发链快照）
- `PERSIST_SCHEMA_DRIFT`（警告）：状态与程序声明不符（不迁移、不丢数据）
- `STATE_REBUILT`（信息）：状态文件缺失或不可读，从默认值重建
- `OBSERVATION_DROPPED`（警告）：观察流发生事件丢失（必须带丢失区间）
- `DEGRADED_FEATURE`（信息）：渲染器不支持某**能力声明之外**的控件 / 属性 / 动效 / 图标 / 几何 / 截图 / 用户动作投递，已明确降级。**必须**带 `feature` 字段（机读）：`geometry` / `snapshot` / `interaction` / `control:<类型>` / `attr:<名>` / `animation:<名>` / `icon:<名>`
- `UNCOVERED_INTERACTION`（警告）：控件的主交互事件（见 `04-vocabulary.md` 第 5.1 节）**既没有处理器、也没有被订阅**——没有任何人在看它，用户操作不会有任何反应
- `UNCOVERED_FAILURE`（警告）：**处理器动作里**的 `call`（即用户触发的能力调用），其 `error` / `timeout` **既没有处理器、也没有被订阅**——调用失败时界面上不会有任何可感知的变化
- `BOUND_VALUE_NOT_WRITTEN`（警告）：控件的 `value` / `selected` 绑定了数据源，且它有 `change` 处理器，但那些处理器**没有回写该数据源**——用户改动会被绑定重算覆盖（界面弹回）
